# Requisitos Nao Funcionais

## RNF-01 - Usabilidade

O sistema deve ser simples de usar, com navegacao intuitiva e poucas etapas para registrar ou atualizar um chamado.

## RNF-02 - Performance

As telas principais devem carregar em tempo adequado para uso operacional, especialmente listagem e detalhe de chamados.

## RNF-03 - Seguranca

O sistema deve exigir autenticacao para acesso a areas internas e proteger dados sensiveis de clientes e atendimentos.

## RNF-04 - Controle de acesso

Usuarios devem visualizar apenas as informacoes permitidas pelo seu perfil.

## RNF-05 - Disponibilidade

O sistema deve estar disponivel em horario comercial com estabilidade suficiente para a operacao da equipe.

## RNF-06 - Rastreabilidade

As acoes principais sobre os chamados devem ficar registradas para consulta posterior.

## RNF-07 - Escalabilidade moderada

O sistema deve suportar crescimento gradual de clientes, usuarios e chamados sem necessidade imediata de reestruturacao completa.

## RNF-08 - Compatibilidade

O sistema web deve funcionar adequadamente nos navegadores mais utilizados em ambiente corporativo.

## RNF-09 - Backup e recuperacao

Os dados devem possuir estrategia de backup e recuperacao compativel com a criticidade do negocio.

## RNF-10 - Manutenibilidade

O sistema deve ser desenvolvido com organizacao suficiente para facilitar manutencao, evolucao e correcoes.

## RNF-11 - Padronizacao

Campos, status e prioridades devem seguir nomenclatura padronizada em todo o sistema.

## RNF-12 - Observabilidade basica

O sistema deve permitir registro de erros tecnicos essenciais para diagnostico de falhas.
