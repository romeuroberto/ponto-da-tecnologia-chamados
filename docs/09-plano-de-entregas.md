# Plano de Entregas

## Fase 1 - Descoberta e validacao

Objetivo:
Validar escopo, processo operacional e regras reais da empresa.

Entregas:

- revisao destes documentos
- definicao do MVP final
- definicao dos perfis de usuario
- definicao do fluxo real de atendimento

## Fase 2 - Especificacao tecnica

Objetivo:
Transformar os requisitos em arquitetura e estrutura de implementacao.

Entregas:

- modelagem de banco de dados
- definicao de API
- wireframes ou telas
- escolha da stack

## Fase 3 - Desenvolvimento do MVP

Objetivo:
Construir a primeira versao utilizavel do sistema.

Entregas:

- autenticacao
- cadastro de clientes
- modulo de chamados
- historico
- dashboard simples

## Fase 4 - Testes e ajustes

Objetivo:
Validar a operacao real com usuarios internos.

Entregas:

- testes funcionais
- correcoes de fluxo
- ajustes de permissao
- refinamentos de usabilidade

## Fase 5 - Implantacao inicial

Objetivo:
Colocar o sistema em uso controlado.

Entregas:

- ambiente publicado
- usuarios cadastrados
- treinamento basico da equipe
- acompanhamento da primeira operacao
